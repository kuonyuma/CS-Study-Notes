# 🗺️ C 语言期末考试极简通关指南 (面向 Java 背景)

## 🎯 0. 明确边界：它解决什么问题？
* **核心价值**：C 语言提供了**直接操作内存**和**贴近底层硬件**的能力。对于期末考试，它主要考察基础的指针操作、数组与字符串处理以及结构体。
* **学习边界**：对于学校期末考试（通常较基础），以下高级特性**暂时不需要深究**：
  * ❌ 复杂的宏定义与预处理（如 `##` 拼接、可变参数宏）
  * ❌ 函数指针与回调函数
  * ❌ 共用体 (`union`) 与位域 (`bit-fields`)
  * ❌ 动态链接库与复杂的 Makefile 构建体系
  * ❌ 复杂的非线性数据结构（如红黑树、图，考试通常只考到单链表或数组）

---

## 🧱 1. 核心学习清单（按推荐顺序）

### 🛑 阶段一：输入输出与类型转换（C 的“基本仪轨”）
> 从 Java 的 `System.out.println` 和 `Scanner` 切换回 C，最容易在格式化输入输出上栽跟头。

* **【要学的具体知识点】**
  * [ ] **格式占位符**：`%d` (int), `%f` (float), `%lf` (double), `%c` (char), `%s` (字符串/字符数组), `%p` (指针地址)。
  * [ ] **`printf` 与 `scanf` 的用法**：理解为什么 `scanf` 需要加取地址符 `&`（如 `scanf("%d", &num)`），而 `printf` 不需要。
  * [ ] **真假值表示**：传统 C89 中没有 `boolean` 类型（Java 的 `true`/`false`），而是用 `0` 表示假，**非 0** 表示真。
  * [ ] **字符与整型隐式转换**：C 语言中 `char` 本质上是一个 1 字节的整数，可以直接与 `int` 进行加减运算（如 `'A' + 32` 得到 `'a'`）。
* **【必须动手的练习】**：
  1. 写一个程序，读取用户输入的一个浮点数，保留两位小数输出。
  2. 读取一个大写字母，输出其对应的小写字母及对应的 ASCII 码。
* **【通关标准】**：能够不看文档，用 `scanf` 正确读入一个整数、一个双精度浮点数和一个字符，并且不出错。

---

### 🛑 阶段二：数组与 Null 结尾的字符串（彻底抛弃 Java String 类）
> Java 的 String 是只读对象，且数组自带 `.length` 属性。C 语言的字符串是“极其原始”的字符数组，且**没有任何越界检查**。

* **【要学的具体知识点】**
  * [ ] **数组越界后果**：C 不会抛出 `ArrayIndexOutOfBoundsException`，只会静默越界读取或引发 `Segmentation fault` (段错误)。
  * [ ] **`\0` (空字符) 终止符**：C 字符串必须以 `\0` 结尾，所以存储长度为 $N$ 的字符串，数组大小至少要声明为 $N+1$。
  * [ ] **常用考试库 `<string.h>` 核心 API**：
    * `strlen(str)`：获取字符串实际长度（不包括 `\0`）。
    * `strcmp(str1, str2)`：比较字符串大小，不能用 `==`（`==` 比较的是地址，因为数组名在比较时会退化为指针）。
    * `strcpy(dest, src)`：拷贝字符串，不能直接 `dest = src`。
    * `strcat(dest, src)`：拼接字符串。
* **【必须动手的练习】**：
  1. 不使用 `<string.h>` 库，手写一个函数实现 `strlen()` 的功能。
  2. 编写一个函数，将输入的字符串进行逆序（反转）。
* **【通关标准】**：能够熟练手写字符串反转算法，并能准确说出 `strcmp` 在各种比较情况下的返回值。

---

### 🛑 阶段三：指针与函数参数传递（C 语言的灵魂）
> Java 中除了基本类型，其他都是“隐式引用”。C 语言显式区分“传值”和“传指针”。

* **【要学的具体知识点】**
  * [ ] **指针基本概念**：`*p`（解引用，访问指针指向的内容）与 `&var`（取地址，获取变量的内存地址）。
  * [ ] **传值与传指针**：为什么 `void swap(int a, int b)` 无法交换主函数中的变量，而必须使用 `void swap(int *a, int *b)`？
  * [ ] **指针与数组的关系**：数组名 `arr` 本质上就是数组首元素的地址 `&arr[0]`，`*(arr + i)` 等价于 `arr[i]`。
  * [ ] **动态内存分配 `<stdlib.h>`**：`malloc` 申请内存，`free` 释放内存。考试中常用于创建动态数组或链表节点。
* **【必须动手的练习】**：
  1. 编写指针版本的经典 `swap` 函数，并在 `main` 函数中成功交换两个整数的值。
  2. 使用 `malloc` 动态申请一个大小为 $N$ 的整型数组，输入数据，求和后用 `free` 释放。
* **【通关标准】**：能够闭眼画出指针指向关系图，并能用指针方式遍历数组。

---

### 🛑 阶段四：结构体与单链表（考试大题常客）
> 结构体 `struct` 是 C 语言的“类”（但只有属性，没有方法）。

* **【要学的具体知识点】**
  * [ ] **结构体声明与初始化**：`struct Student { char name[20]; int age; };`。
  * [ ] **成员访问符**：结构体变量用 `.`（如 `stu.age`），结构体指针用 `->`（如 `pStu->age`）。
  * [ ] **单链表的建立与遍历**：如何定义链表节点，如何头插法/尾插法建立单链表，以及如何遍历输出链表。
* **【必须动手的练习】**：
  1. 定义一个学生结构体，包含学号、姓名、成绩。编写程序读取 3 个学生的数据，并输出成绩最高者的信息。
  2. 实现一个最基础的单链表：创建 3 个节点，并顺序输出它们的值。
* **【通关标准】**：能够手写出定义链表节点结构体，并实现链表尾部插入新节点的核心代码。

## 💻 2. OJ 专项：输入与输出模式通关

学校考试如果采用 OJ (Online Judge) 平台，输入输出的数据流处理与常规开发大不相同。你需要掌握以下核心套路：

### 1. 多组测试数据输入模式 (EOF)
* **场景一：未说明数据组数，读到文件末尾 (EOF) 为止**
  * **套路代码**：
    ```c
    int a, b;
    while (scanf("%d %d", &a, &b) != EOF) {
        // 处理单组测试数据的逻辑
        printf("%d\n", a + b);
    }
    ```
    *💡 注：在本地终端测试时，可通过按下 `Ctrl + Z` (Windows) 或 `Ctrl + D` (Linux/Mac) 并回车来手动模拟 EOF。*

* **场景二：第一行给出数据组数 $T$，接下来有 $T$ 组数据**
  * **套路代码**：
    ```c
    int T;
    if (scanf("%d", &T) == 1) {
        while (T--) {
            int a, b;
            scanf("%d %d", &a, &b);
            // 处理单组数据
            printf("%d\n", a + b);
        }
    }
    ```

* **场景三：以特定输入结束（如输入为 0 时结束，不需要处理该 0）**
  * **套路代码**：
    ```c
    int n;
    while (scanf("%d", &n) == 1 && n != 0) {
        // 处理非 0 数据
    }
    ```

---

### 2. 带空格的字符串读入
* **痛点**：`scanf("%s", str)` 遇到空格、制表符（Tab）或回车就会停止读取，无法读入整行。
* **套路代码**：
  * **方案 A：`fgets` (推荐，安全且标准)**
    ```c
    char str[100];
    fgets(str, sizeof(str), stdin);
    // 注意：fgets 会把末尾的回车 '\n' 也读进去，需要手动去掉：
    str[strcspn(str, "\n")] = '\0';
    ```
  * **方案 B：`gets` (考场常用，但已被 C11 标准废弃)**
    ```c
    char str[100];
    gets(str); // 自动丢弃换行符，但极不安全，容易缓冲区溢出
    ```

---

### 3. 输出格式陷阱（防止 Presentation Error / 格式错误）
* **陷阱一：行尾多余的空格**
  * 题目通常要求“输出一行 $N$ 个数，用空格分隔，**行末无多余空格**”。
  * **错误示范**：`for(int i = 0; i < n; i++) printf("%d ", a[i]);` (行末多了空格，会导致 OJ 判错)
  * **正确示范（使用三目运算符）**：
    ```c
    for (int i = 0; i < n; i++) {
        printf("%d%c", a[i], i == n - 1 ? '\n' : ' ');
    }
    ```
* **陷阱二：浮点数精度控制**
  * 浮点数保留 $k$ 位小数：使用 `%.kf`（如保留两位：`printf("%.2f\n", result);`，注意 `double` 类型在 `printf` 中也推荐用 `%f` 控制输出）。

## ⚠️ 3. 避坑指南（从 Java 转 C 的新手保护垫）

### 1. `scanf` 缓冲区残留问题（考试最爱考！）
* **陷阱**：在读取完数字或字符串后，如果立刻用 `scanf("%c", &ch)` 或 `getchar()` 读取字符，会直接读入刚才残留的回车换行符 `\n`。
* **解法**：在 `%c` 前加一个空格，写成 `scanf(" %c", &ch)`，这可以**自动忽略**前面的所有空白字符（回车、空格、Tab）。

### 2. 字符串比较千万别用 `==`
* **陷阱**：
  ```c
  char str1[] = "hello";
  if (str1 == "hello") { ... } // 永远为假！因为 == 比较的是地址
  ```
* **解法**：必须使用 `strcmp(str1, "hello") == 0`。

### 3. 未初始化指针（野指针）
* **陷阱**：Java 中未初始化的引用是 `null`，调用会抛出 `NullPointerException`。而 C 语言中本地指针如果不初始化，会指向一个**随机内存地址**。直接向其写入数据会导致程序崩溃或篡改其他数据！
* **解法**：定义指针时如果暂不用，一律初始化为 `NULL`：`int *p = NULL;`。

### 4. 浮点数除法整除陷阱
* **陷阱**：这与 Java 类似，但很容易手抖：`double result = 1 / 2;` 得到的是 `0.0`。
* **解法**：必须确保至少有一个是浮点数：`1.0 / 2` 或 `(double)a / b`。

### 5. `printf` 格式不匹配
* **陷阱**：将 double 类型的数据用 `%f` 读入，或者用 `%d` 打印 double。C 语言是不安全的强类型，它会按照你指定的格式硬塞字节，导致输出诡异的数字或 0。
* **解法**：严格记忆：
  * `scanf` 读入 `double` 必须用 `%lf`，而 `printf` 打印 `double`/`float` 均可用 `%f`（C99中 printf 也支持 %lf，但用 %f 最稳妥）。
  * 读写 `int` 用 `%d`。
  * 读写字符用 `%c`。
