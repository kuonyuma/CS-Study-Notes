# CSS 定位 (Position) 学习路线图与核心知识清单

这是一份为你量身定制的 CSS 定位学习清单。根据教材要求，网页布局的三大机制是**标准流、浮动和定位**。

当我们需要让盒子**在页面中自由重叠移动**、或者**固定在屏幕某个位置不随滚动条滚动**时，标准流和浮动就无能为力了，这时必须使用**定位 (Position)**。

---

## 阶段一：前置准备与核心要素（为什么需要定位）

- [ ] **理解定位的组成公式**：
  $$\text{定位} = \text{定位模式 (position)} + \text{边饰/偏移量 (top/right/bottom/left)}$$
  * **定位模式**：用 CSS 的 `position` 属性指定，决定这个盒子**以谁为参照物**来移动。
  * **边饰/偏移量**：用 `top`、`bottom`、`left`、`right` 指定具体的移动距离（如 `top: 10px;` 表示距离参照物顶部 10 像素）。
- [ ] **心智模型——3D 图层概念**：
  * 标准流和浮动元素基本在二维桌面上排版。
  * **定位（除了静态定位）则会把盒子抬升到 3D 空间的更高图层上**，使元素之间可以互相重叠覆盖。

---

## 阶段二：定位模式的四大分类（核心基础）

掌握 position 属性的四种核心取值及其行为特点（期末必考对比题）：

- [ ] **1. 静态定位 `position: static;`（默认）**：
  * **特点**：就是无定位，元素乖乖呆在**标准流**里。设置 `top/left` 等偏移量无效。
- [ ] **2. 相对定位 `position: relative;`（“精神出轨”型）**：
  * **参照物**：以自己**原本在标准流中的位置**为基准点进行移动。
  * **空间占用（重要）**：**不脱标**。即使它通过 `top: 50px` 移走了，它原本在地面上占用的空间依然被保留着（别的元素不能顶上来）。
- [ ] **3. 绝对定位 `position: absolute;`（“彻底脱轨”型）**：
  * **参照物**：以**最近的一级有定位（relative/absolute/fixed）的祖先元素**为基准进行移动。如果所有祖先元素都没有定位，则以浏览器视口（`body`）为准。
  * **空间占用（重要）**：**脱标**。完全飘走，原标准流空间腾空，其他元素会顶上去。
- [ ] **4. 固定定位 `position: fixed;`（“钉死在屏幕”型）**：
  * **参照物**：永远以**浏览器可视窗口**为基准点移动。
  * **空间占用**：**脱标**。无论页面怎么往下拉，它都雷打不动地钉在屏幕的指定位置（常用于返回顶部按钮、固定导航栏）。

---

## 阶段三：黄金布局搭档——“子绝父相” 🌟（超级重难点）

在实际开发和期末大题中，最常用的定位组合就是**子级使用绝对定位，父级使用相对定位**。

- [ ] **为什么叫“子绝父相”？**：
  * **子级绝对定位 (`absolute`)**：为了让子盒子在父盒子内部任意自由移动，不占位置，不影响其他兄弟元素。
  * **父级相对定位 (`relative`)**：为了给子盒子的绝对定位提供一个**参考基准边界**；同时因为相对定位**不脱标**，父盒子依然在标准流里占着空间，不会导致后面的网页布局塌陷错乱。
- [ ] **典型应用场景**：
  * 淘宝轮播图的左右切换箭头、底部圆点，都是利用“子绝父相”定位在轮播图大框内部的。

---

## 阶段四：空间立体感——`z-index` 与定位特殊性

- [ ] **`z-index`（堆叠顺序/层级）**：
  * 决定重叠元素的上下摆放顺序。数值越大，盒子越靠上显示（如 `z-index: 10;` 会盖在 `z-index: 1;` 上面）。
  * **⚠️ 注意**：`z-index` 属性**只有在元素设置了定位（relative/absolute/fixed）时才有效**。对普通标准流的 `static` 元素无效。
- [ ] **定位元素的“块级转换”**：
  * 类似于浮动，行内元素（如 `span`）一旦设置了**绝对定位**或**固定定位**，也会自动转为块级行为，可以直接设置宽度和高度。

## 阶段五：实战演练与防灾避坑指南

- [ ] **淘宝轮播图点位居中技巧（绝对定位的水平居中）**：
  * 绝对定位的盒子无法直接通过 `margin: 0 auto;` 居中。
  * **经典居中算法公式**：
    1. 先让盒子靠左移到父盒子的一半：`left: 50%;`
    2. 再让盒子往回走自己宽度的一半：`margin-left: -50px;`（假设盒子宽 100px），或者使用 CSS3 的变形：`transform: translateX(-50%);`。
- [ ] **避坑：绝对定位元素不占高度**：
  * 如果父盒子里所有的子元素都是绝对定位，因为它们都飘走了，父盒子的高度会塌陷为 0（跟浮动类似，但不能用清除浮动来解决，只能给父盒子手动写死高度）。
