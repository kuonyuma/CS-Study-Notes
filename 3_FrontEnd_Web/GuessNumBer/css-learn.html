① display: flex — 弹性布局

默认情况下，div 是块级元素，会垂直堆叠。 加上 display: flex 后，子元素会变成水平排列。 

/* 没有 flex（默认）*/
div { display: block; }   /* 子元素垂直堆叠 */

/* 开启 flex */
div { display: flex; }    /* 子元素水平排列 */

开启 flex 后，用这三个属性控制子元素的排列方式：

justify-content:  子元素沿主轴的对齐方式（横向）
align-items:      子元素沿交叉轴的对齐方式（纵向）

③ min-height: 100vh — 最小占满全屏

vh = viewport height，视口高度的 1%。
100vh = 屏幕的全部高度。
min-height: 100vh 的意思是：内容少时至少撑满屏幕，内容多时可以继续增长。 

/* height: 100px → 固定死，内容超出会溢出 */
/* min-height: 100px → 至少100px，内容多了会自动变高 */

body {
  min-height: 100vh; /* 页面至少占满整个屏幕 */
}

④ position: relative & absolute — 定位

这是图片切换案例里最关键的 CSS！
relative：给子元素提供定位参考点（父容器本身不动）。
absolute：脱离文档流，相对于最近的 relative 父元素精确定位，多个 absolute 子元素会互相叠放。 

/* 父容器：设为 relative，作为坐标系原点 */
.slider { position: relative; }

/* 子元素：absolute 脱离文档流，全部叠在同一位置 */
.slide  { position: absolute; top: 0; left: 0; }

→ 蓝色盒子和红色徽标都是 absolute，它们叠放在同一个 relative 父容器内，互相不占位。

⑤ opacity — 透明度

取值范围 0 ~ 1：0 完全透明（隐藏），1 完全不透明（显示）。
图片切换中，默认 opacity: 0 隐藏所有图片，当前图片设为 opacity: 1 显示。 

.slide        { opacity: 0; }  /* 隐藏 */
.slide.active { opacity: 1; }  /* 显示 */

→ 注意：opacity: 0 只是视觉上隐藏，元素仍然占据空间，这与 display: none（完全移除）不同。

⑥ transition — 过渡动画

当某个 CSS 属性发生变化时，transition 让这个变化平滑过渡而不是瞬间跳变。 

/* 格式：transition: 属性名  持续时间  缓动方式 */
transition: opacity 0.5s ease-in-out;
transition: background 0.3s, transform 0.3s; /* 可同时监听多个属性 */

⑦ object-fit — 图片填充方式

当图片尺寸与容器尺寸不一致时，object-fit 控制图片如何填充容器。 

img {
  width: 100%;
  height: 100px;
  object-fit: cover;   /* 推荐：等比裁剪，不变形 */
}

⑧ margin / padding / gap — 间距三兄弟

padding：元素内部的间距（内容到边框的距离）。
margin：元素外部的间距（与其他元素的距离）。
gap：flex 布局中，子元素之间的间距。 

padding: 20px;           /* 内边距：上下左右都是 20px */
padding: 10px 30px;      /* 上下 10px，左右 30px */
margin: 20px 0;          /* 上下 20px，左右 0 */
gap: 16px;               /* flex 子元素之间的间距 */

⑩ cursor & :hover — 鼠标样式与悬停效果

cursor：鼠标移到元素上时显示什么图标。
:hover：伪类，当鼠标悬停在元素上时，自动应用的样式，不需要 JS。 

button { cursor: pointer; }     /* 鼠标变成手型 */

/* :hover 伪类：鼠标悬停时触发 */
button:hover {
  background: #357abd;          /* 颜色变深 */
}

▼ 将鼠标移到各盒子上，观察鼠标图标变化：

cursor: default（箭头）
cursor: pointer（手型 👆）
cursor: text（文字）
cursor: not-allowed（禁止）
