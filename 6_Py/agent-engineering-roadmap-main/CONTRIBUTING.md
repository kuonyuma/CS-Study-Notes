# Contributing

Thanks for helping builders learn agent engineering.

**Welcome PRs:**
- Fixing broken links or outdated claims (tools move fast; guides date)
- Bug fixes and dependency bumps in `labs/`
- Suggesting a genuinely better free resource for a stage (explain why it beats what's listed)

**Not accepted:**
- Link swaps, sponsored placements, or self-promotional listicle additions
- New stages or restructures without an issue discussion first
- Content copied from paywalled sources

**Ground rule:** we only list resources we'd point a builder to ourselves. Every addition needs a one-line justification in the PR description: what does a reader learn here that the existing links don't teach?

For lab changes, make sure `npm start` works on Node 20+ before opening the PR.
